# 日本の化学企業｜規模順リスト

連結売上高を主キーに、日本の化学企業を規模の大きい順に整理したExcelです。

## ファイル

- [`日本化学企業_規模順リスト.xlsx`](./日本化学企業_規模順リスト.xlsx)

## シート構成

| シート | 内容 |
| --- | --- |
| `0_早見ランキング` | 順位・企業名・売上・本社都道府県・メールドメイン |
| `1_規模基準` | 規模判定に使う全要素（売上・利益・時価総額・従業員・R&D等） |
| `2_企業規模ランキング` | 本社・主要R&D拠点・メール法則・代表例つき詳細表 |
| `3_メールアドレス法則` | ドメイン法則・ローカル部命名規則・主要企業早見 |
| `4_注記と出典` | 前提・出典・更新方針 |

## 再生成

```bash
python3 create_chemical_companies_excel.py
```

売上・時価総額等は概算です。投資判断には各社の有価証券報告書を参照してください。メールの個人名部分は法則説明用の仮想例です。
